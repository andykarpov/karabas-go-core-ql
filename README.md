# Sinclair QL for Karabas Go

The Sinclair QL for the Karabas Go board family (Xilinx Spartan-6 XC6SLX25): a port of the [QL core of the ZX Spectrum Next](https://gitlab.com/thesmog358/qlnext) by Theodoulos Liontakis, based on the MiST port by Till Harbaum and Victor Trucco.

Work in progress, see `docs/PLAN.md` (in Russian).
