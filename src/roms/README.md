# ROMs

Built into the `.kg` (user's decision 2026-11-08), from the ZX Spectrum Next distribution,
https://gitlab.com/thesmog358/tbblue `machines/ql`:

- `min198a1.rom`: Minerva 1.98a1, 48 KB, the QL operating system (at 000000).
- `qlsd.rom`: the QLFAT32 driver, 32 KB, the back ROM (at 00C000).

The `FL` items of the core replace them from `/ql` on the SD card.
