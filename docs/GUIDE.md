# Sinclair QL на Karabas: руководство

## Что это

Sinclair QL (1984) — 32-битный по архитектуре домашний компьютер на процессоре Motorola 68008, с многозадачной ОС QDOS и языком SuperBASIC. Экран 512 × 256 в 4 цветах или 256 × 256 в 8 цветах, штатные накопители — картриджи Microdrive.

Ядро для плат Karabas Go, Mini и Mini G — порт [ядра QL для ZX Spectrum Next](https://gitlab.com/thesmog358/qlnext) (Theodoulos Liontakis), основанного на ядре MiST (Till Harbaum, Victor Trucco).

### Что есть

| | |
|---|---|
| Процессор | TG68K в режиме 68000, 10,83 МГц; намного быстрее настоящего QL |
| ОЗУ | 1920 КБ |
| ОС | Minerva 1.98a1 встроена в ядро; другую ОС можно загрузить файлом |
| Видео | HDMI (Go: VGA) 1024 × 768 @ 60 Гц: режимы 4 и 8 QL, 16 и 256 цветов ядра Next |
| Звук | бипер IPC, AY (QSound), HDMI и аудиовыход платы |
| Накопитель | SD-карта на образе через драйвер QLFAT32 (встроен в ядро), чтение и запись |
| Мышь | USB, совместима с QIMI |
| Джойстики | USB: первый порт — курсоры и пробел, второй — F1…F5 |
| Часы | дата и время берутся из часов платы при каждом старте |
| MIDI | USB MIDI-клавиатура и встроенный синтезатор платы, см. ниже |

### Отличия и ограничения

- **Microdrive пока не работает.** Образ загружается, но `dir mdv1_` отвечает `not found`. Причина не найдена.
- Процессор не потактово точный: часть старых игр может идти слишком быстро.
- Нет сети QLNet, последовательных портов, спрайтов и PCM-звука ядра Next (KS2).
- Основные функции проверены на Mini G. **Сборки для Go и Mini не запускались на платах, MIDI не проверялся ни на одной плате.**
- Звук синтезатора подмешан в общий выход (HDMI и аудиовыход) только на Mini G. В сборках Go и Mini этого подмеса нет.

## Что куда класть

| Файл | Куда | Зачем |
|---|---|---|
| `ql.kg` | корень SD-карты | само ядро |
| `*.img` | `/ql` | образ SD-карты для QL |
| `*.rom`, `*.bin` | `/ql` | другая ОС или ROM расширения (по желанию) |

Папку `/ql` создайте сами. Без файлов ядро стартует: нужные ROM встроены.

## Первый запуск

После старта Minerva показывает подсказку:

- **F1** — режим монитора (текст 85 колонок, для HDMI это правильный выбор);
- **F2** — режим TV (40 колонок);
- F3 / F4 — то же с двумя экранами.

Если не нажимать ничего около 10 секунд, Minerva сама выберет TV. Дальше — приглашение SuperBASIC. Например:

```
print date$
beep 20000,10
mode 8
```

## Меню OSD

Открывается **Menu+Esc**.

| Пункт | Клавиша | Что делает |
|---|---|---|
| OS ROM | Menu+F1 | загрузить другую ОС (48 КБ или 64 КБ) и перезапустить машину |
| Back ROM | Menu+F2 | загрузить ROM расширения по адресу $C000 (заменяет встроенный драйвер QLFAT32) |
| MDV1 | Menu+F3 | образ Microdrive, 174930 байт, формат QLAY; пока не читается QDOS |
| SD card | Menu+F4 | образ SD-карты |
| Reset | F12 | сброс |
| MDV order | | порядок секторов образа |
| SD2 card | | второй слот SD как настоящая карта, по умолчанию выключено |
| MDV speed | | скорость Microdrive: 200 или 722 кбит/с |
| MIDI thru | | USB-клавиатура сразу играет на синтезаторе платы |

## Клавиатура

Обычные клавиши — как на ПК. Особые:

| ПК | QL |
|---|---|
| Backspace | Ctrl+Left: удалить символ слева |
| Delete | Ctrl+Right: удалить символ справа |
| Page Up / Page Down | Shift+Up / Shift+Down |
| Home / End | Alt+Left / Alt+Right |
| F6…F10 | Shift+F1…Shift+F5 |
| Esc | Esc (прерывание в BASIC — Ctrl+Space) |

## Образ SD-карты

QL видит образ как настоящую SD-карту: нужна таблица разделов MBR и раздел FAT32. Подойдёт и образ, снятый с настоящей карты. Драйвер показывает разделы как `sda1_`, `sda2_` и так далее.

Создать образ на Linux (пакеты `mtools`, `util-linux`):

```sh
dd if=/dev/zero of=sd.img bs=1M count=64
printf 'label: dos\nstart=2048, type=c\n' | sfdisk sd.img
mformat -i sd.img@@1M -F -c 1 -v QLCARD ::
mcopy -i sd.img@@1M MYFILE.TXT ::
mdir -i sd.img@@1M ::
```

Минимальный размер для FAT32 — примерно 33 МБ. Положите `sd.img` в `/ql` и выберите его в OSD (Menu+F4), затем нажмите F12.

Проверка:

```
dir sda1_
copy "sda1_hello.txt" to "sda1_new.txt"
```

Имя с точкой в `COPY` пишите в кавычках.

Строка драйвера при старте `SDA:y` означает, что карта найдена. Драйвер также знает файл `sda1_boot`: судя по его коду, он запускает его при старте; это пока не проверялось.

Команды драйвера: `DIR`, `COPY`, `MAKE_DIR`, `CHANGE_DIR`, `REMOVE_DIR`, `CURRD$`, `EJECT`, `SD_SWAP`, `SDA_USE`, `SDB_USE`, `CHKSD`, `SDTK_EXT`, `XTCC`.

Образ лучше делать один раз и не фрагментировать: создайте файл целиком.

### Вторая карта (SD2)

Пункт **SD2 card = On** отдаёт драйверу настоящую карту из второго слота как `sdb1_`. Драйвер пишет на подключённую карту, поэтому не включайте этот пункт, если на карте есть важные данные. Режим на плате ещё не проверялся.

### Диски QXL.WIN

Контейнеры `QXL.WIN` (формат QPC2, QemuLator, QL-SD) лежат в корне раздела. Чтобы подключить такой файл как `win1_`, нужен драйвер `qlwa_rext` (`LRESPR`, после тулкитов), а он не входит в ядро. Пока этот путь не проверялся.

## Где брать софт и игры

- [Dilwyn Jones: Sinclair QL Pages](https://www.sinclairql.net/) — самый большой архив: ОС, игры, утилиты, документация. [Страница ROM](https://www.sinclairql.net/djw/qlrom/index.html).
- [The Sinclair QL Forum](https://theqlforum.com/) — форум сообщества.
- [Дистрибутив ZX Next, папка `machines/ql`](https://gitlab.com/thesmog358/tbblue) — ROM и драйверы этого ядра, а также образы в `mdvs/`.
- [QL на MiSTer](https://www.kilgus.net/ql/mister/) (Marcel Kilgus) — ОС и демо-образ `QXL.WIN`.

Большинство игр и программ распространяются как образы Microdrive или дискет. Пока Microdrive не работает, их файлы нужно переносить на SD-образ: распаковать на ПК и скопировать в раздел FAT32. Учтите, что исполняемым файлам QDOS нужен заголовок, который при простом копировании теряется; эмуляторы и архивы zip для QL его сохраняют по-разному.

## Режимы экрана

- `mode 4` — 512 × 256, 4 цвета; `mode 8` — 256 × 256, 8 цветов.
- Расширения ядра Next (через порты): 16 цветов и 256 цветов.

```
poke 8388622,1 : rem 256 цветов
poke 8388622,0 : rem обычный режим
```

## MIDI

К USB можно подключить MIDI-клавиатуру. Пока включён **MIDI thru**, она сразу играет на синтезаторе SAM2695 платы.

Порты для программ на QL (стандартного MIDI у QL нет, готовых драйверов тоже):

| Адрес | Чтение | Запись |
|---|---|---|
| $800026 (8388646) | бит 0 — есть принятый байт, бит 1 — можно передавать | |
| $800027 (8388647) | следующий принятый байт (снимается из очереди) | байт на синтезатор |

Сыграть ноту из BASIC (канал 1, нота 60, громкость 100):

```
poke 8388647,144
poke 8388647,60
poke 8388647,100
```

Выключить её — те же байты с громкостью 0.

## Если что-то не так

- **`dir mdv1_` отвечает `not found`** — так сейчас и есть, см. выше.
- **`dir sda1_` отвечает `not found`** — образ не смонтирован, нет раздела MBR с FAT32, либо после монтирования не было сброса F12.
- **При загрузке нет реакции на F1** — подождите конца теста памяти, подсказка появляется примерно через 5–8 секунд.
- **Слишком быстрая игра** — режима с настоящей скоростью QL пока нет.
