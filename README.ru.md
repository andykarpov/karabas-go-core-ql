# Ядро Sinclair QL для Karabas Go / Mini / Mini G

[English version](README.md)

Домашний компьютер **Sinclair QL** для плат семейства Karabas Go (Xilinx Spartan-6 XC6SLX25). Это порт [ядра QL для ZX Spectrum Next](https://gitlab.com/thesmog358/qlnext) Теодулоса Лионтакиса, основанного на ядре MiST Тилля Харбаума и Виктора Труко. Один файл ядра `ql.kg` на все три платы.

| Плата | Видео | Звук | Синтезатор в миксе |
|---|---|---|---|
| Karabas Go | VGA 1024 × 768 60 Гц | I2S ЦАП (PCM5102) | нет |
| Karabas Mini | HDMI 1024 × 768 60 Гц | HDMI, аналоговый выход (сигма-дельта) | нет |
| Karabas Mini G | HDMI 1024 × 768 60 Гц | HDMI, I2S ЦАП (PCM5102) | да |

Состояние: сборка 26110908. На Mini G проверены Minerva, видео, клавиатура, кнопки и движение мыши, часы, звук, образы SD-карты (чтение и запись). **Microdrive пока не работает.** Сборки для Go и Mini на платах не запускались, MIDI не проверялся ни на одной плате.

Подробное руководство: [docs/GUIDE.md](docs/GUIDE.md). Открытые задачи: [docs/BACKLOG.md](docs/BACKLOG.md).

## Машина

Sinclair QL (1984) — компьютер на процессоре Motorola 68008 с многозадачной ОС QDOS и языком SuperBASIC. Экран 512 × 256 в 4 цветах или 256 × 256 в 8 цветах.

В ядре есть:

- **Процессор:** TG68K в режиме 68000, 10,83 МГц, намного быстрее настоящего QL.
- **Память:** 1920 КБ.
- **ОС:** Minerva 1.98a1 встроена в ядро, другую ОС можно загрузить с SD-карты.
- **Видео:** режимы QL 4 и 8, а также 16 и 256 цветов ядра Next.
- **Звук:** бипер IPC и AY ядра Next.
- **Накопитель:** образ SD-карты через встроенный драйвер QLFAT32, чтение и запись.
- **Мышь:** USB, видна как интерфейс QIMI.
- **Джойстики:** USB. Первый работает как курсоры и пробел, второй как F1…F5.
- **Часы:** дата и время берутся из часов платы при каждом старте.
- **MIDI:** USB MIDI-клавиатура и MIDI OUT на синтезатор SAM2695 платы.

## Что куда класть

| Файл | Куда | Зачем |
|---|---|---|
| `ql.kg` (лежит в `src/`) | корень SD-карты | ядро |
| `*.img` | `/ql` | образы SD-карты для QL |
| `*.rom`, `*.bin` | `/ql` | другая ОС или ROM расширения (по желанию) |

Папку `/ql` создайте сами. Без файлов ядро стартует: нужные ROM находятся внутри `ql.kg`.

## Первый запуск

1. Скопируйте `ql.kg` на SD-карту и выберите **Sinclair QL** в меню ядер.
2. После теста памяти (5–8 секунд) Minerva спросит режим экрана. **F1** — режим монитора (85 колонок, правильный выбор для HDMI), **F2** — режим TV (40 колонок), F3 и F4 — то же с двумя экранами. Если не нажимать ничего около 10 секунд, Minerva сама выберет TV.
3. Появится приглашение SuperBASIC. Попробуйте:

```
print date$
beep 20000,10
mode 8
```

## Меню OSD

Открывается **Menu+Esc**. Menu — клавиша Windows на клавиатуре.

| Пункт | Значения | Клавиша |
|---|---|---|
| OS ROM | файл 48 КБ или 64 КБ, машина перезапускается | Menu+F1 |
| Back ROM | ROM по адресу $C000, заменяет встроенный QLFAT32 | Menu+F2 |
| MDV1 | образ `.mdv`, 174930 байт (пока не читается QDOS) | Menu+F3 |
| SD card | образ `.img` | Menu+F4 |
| Reset | сброс машины | F12 |
| MDV order | Normal / Reverse | |
| SD2 card | Off (по умолчанию) / On | |
| MDV speed | Normal / Fast (по умолчанию) | |
| MIDI thru | Off / On (по умолчанию) | |

**SD2 card = On** отдаёт драйверу настоящую карту из второго слота как `sdb1_`. Драйвер пишет на подключённую карту, поэтому не включайте этот пункт, если на карте есть важные данные. На плате этот режим не проверялся.

## Клавиатура

Большинство клавиш работает как на ПК. Особые:

| ПК | QL |
|---|---|
| Backspace | Ctrl+Left: удалить символ слева |
| Delete | Ctrl+Right: удалить символ справа |
| Page Up, Page Down | Shift+Up, Shift+Down |
| Home, End | Alt+Left, Alt+Right |
| F6…F10 | Shift+F1…Shift+F5 |
| Esc | Esc (прервать программу на BASIC: Ctrl+Space) |

## Образы SD-карты

QL видит образ как настоящую SD-карту, поэтому нужны таблица разделов MBR и раздел FAT32. Подойдёт и образ, снятый с настоящей карты. Драйвер называет разделы `sda1_`, `sda2_` и так далее.

На Linux (пакеты `mtools`, `util-linux`):

```sh
dd if=/dev/zero of=sd.img bs=1M count=64
printf 'label: dos\nstart=2048, type=c\n' | sfdisk sd.img
mformat -i sd.img@@1M -F -c 1 -v QLCARD ::
mcopy -i sd.img@@1M MYFILE.TXT ::
```

Минимальный размер для FAT32 — примерно 33 МБ. Положите `sd.img` в `/ql`, выберите его в OSD (Menu+F4) и нажмите F12. Затем:

```
dir sda1_
copy "sda1_hello.txt" to "sda1_new.txt"
```

Имя с точкой в `COPY` пишите в кавычках. Строка драйвера `SDA:y` при старте означает, что карта найдена.

Для контейнеров `QXL.WIN` (QPC2, QemuLator) нужен драйвер `qlwa_rext`, которого нет в ядре. Этот путь не проверялся.

## MIDI

Подключите USB MIDI-клавиатуру. Пока включён **MIDI thru**, она сразу играет на синтезаторе платы.

MIDI-порта у QL нет, готовых программ для этого тоже. Программы могут работать с портами:

| Адрес | Чтение | Запись |
|---|---|---|
| $800026 (8388646) | бит 0 — есть принятый байт, бит 1 — можно передавать | |
| $800027 (8388647) | следующий принятый байт из очереди на 64 байта | байт на синтезатор |

Нота из BASIC (канал 1, нота 60, громкость 100):

```
poke 8388647,144
poke 8388647,60
poke 8388647,100
```

Большинство программ распространяется как образы Microdrive или дискет. Пока Microdrive не работает, файлы нужно переносить на SD-образ. Исполняемым файлам QDOS нужен заголовок, который при простом копировании теряется.

## Ограничения

- Microdrive не работает: образ загружается, но `dir mdv1_` отвечает `not found`. Причина не найдена.
- Режима со скоростью настоящего QL нет, часть старых игр может идти слишком быстро.
- Не поддерживаются сеть QLNet, последовательные порты, спрайты и PCM-звук ядра Next.
- Нет драйвера QDOS для портов MIDI.
- Звук синтезатора попадает в общий выход только на Mini G.

## Сборка

Клонируйте с `--recursive` (подмодуль `modules`). ISE 14.7: `cd src && make` для всех плат или `make minig` (`go`, `mini`) для одной, результат — `src/ql.kg`. Верхи Go и Mini генерируются из верха Mini G скриптом `src/tools/gen_tops.py`.

Симуляция машины (ghdl и Verilator): `src/sim/run_boot.sh`. План и решения: [docs/PLAN.md](docs/PLAN.md).
